AI FOR LEADERS · KIT
====================

Everything in this kit is invented for training. The tools, numbers, places
and events are made up and are not from any real fab. People are named by
role, not by name.

HOW TO USE IT
1. Open Copilot Chat (the training invite explains how).
2. Start a NEW chat for each exercise.
3. Upload the files the slide names, or open each one, copy all the text and
   paste it.
4. Copy the prompt from playbook-prompts.txt and paste it.

WHAT'S IN IT
consolidation_plan.txt     The case: a plan to move two etch tool sets onto
                           one line. Used in all three exercises.
decision_frame.txt         The confirmed frame for the decision. Goes to the
                           chat that builds the brief.
my_leaning.txt             What the decision owner leans toward. Goes ONLY to
                           the chat that makes the case against.
playbook-prompts.txt       Every prompt in the playbook, ready to copy.
ops_review_transcript.txt  A meeting transcript to practise the meeting-notes
                           prompt at home.

EXERCISES
Build the brief      new chat · consolidation_plan.txt + decision_frame.txt
                     · prompt 2
Review the brief     new chat · consolidation_plan.txt · prompt 3 · your brief
Case against         new chat · my_leaning.txt · prompt 4 · your brief

Keep playbook-prompts.txt. Copy it into your own document. When a prompt
misses something, change it, raise the version and log the change. That
document is your playbook.
