# AI Training Curriculum

© 2026 SkyWater Technology. Proprietary. Keep this repository private.

In-person AI training for fab staff. Decks are self-contained HTML: open them in a browser to present.

## Courses

| Course | Audience | Length | Deck | Hands-on kit |
|---|---|---|---|---|
| AI Basics (start here, prerequisite for all) | Everyone | 90 min | `AI-Basics.html` | `AI-Basics-practice-pack.zip` |
| AI for Troubleshooting | Engineers and equipment technicians | 90 min | `AI-for-Troubleshooting.html` | `AI-for-Troubleshooting-case-kit.zip` |
| AI for Process Development | Process engineers | 90 min | `AI-for-Process-Development.html` | `AI-for-Process-Development-kit.zip` |
| AI for Leaders | Managers and executives | 50 min | `AI-for-Leaders.html` | `AI-for-Leaders-kit.zip` |

## Folder layout

- `*.html`: the four course decks.
- `*.zip`: kits handed to attendees, built from the matching kit folders.
- `basics-practice-pack/`, `troubleshooting-kit/`, `process-development-kit/`, `leaders-kit/`: kit contents. All data is synthetic. `source/` holds the instructor key and generator scripts (not for attendees).
- `cheat-sheets/`: take-away cheat sheets and before-you-come sheets (HTML and PDF).
- `workflows/`: course playbooks and worked examples.
- `reference/`: Systems Engineering Playbook v2 (the playbook standard), prompt evaluation rubric, its evidence, and the prompt grader.
- `curriculum-map.md`: what each course covers, to avoid overlap.
- `trainer-vision-brief.md`: notes for the trainer.
