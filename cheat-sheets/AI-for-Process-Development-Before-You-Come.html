AI for Process Development · Before you come

Five things to do before the session.

The whole session is hands-on, on your own laptop, in Gemini Enterprise. If any of these isn't done, you'll spend the session watching instead of working.

1

Get a Gemini Enterprise seat

Required. The exercises use Gemini Enterprise chat with file upload, and Gemini writing and running code to check the numbers. Seats cost money, so your manager approves them with a short justification. Ask at least two weeks before your session.

A justification you can adapt

I run [process improvement projects, DOEs, recipe changes] about [N] times a quarter. Gemini Enterprise lets me plan experiments with a reviewed, shared playbook, check run sheets and data by code instead of by eye, and hand on plans others can trust. I expect it to save about [X] hours per project. It is required for the AI for Process Development course on [date].

Managers: the course can't be done in Copilot Chat. Approving the seat before the session is what makes the 90 minutes worth it.

2

Sign in once, before the day

  1. Open Gemini Enterprise and start a chat.
  2. Upload any small CSV and ask: "Write and run code to count the rows."
  3. Check that it shows the code and a result, not just an answer.
  4. Open a second chat. You'll use several at once.

If any step fails, contact IT or Andrew before the session, not during it.

3

Bring your laptop

  • Charged, with the charger
  • Able to reach Gemini Enterprise from the training room network
  • Signed in to your SkyWater account
4

Download the project kit

Unzip AI-for-Process-Development-kit.zip from the invite to a folder you can find. It has a project brief, tool limits, old tech reports, SPC history, a process flow, experiment results, the Plan an Experiment playbook (every prompt from the session) and a worked example with ready answers.

Every file is synthetic training data, safe to upload. Don't bring real data; we won't use it in class.

5

Have AI Basics fresh

This course builds on AI Basics and won't repeat it. You should be comfortable with:

  • Having a back-and-forth conversation with it, not one perfect prompt
  • Giving it the source, and checking what it says against it
  • The desk card: Ask, Refine, Check, Send

Haven't taken it, or it's been a while? Read the AI Basics desk card (one page).

★

Optional

Think of one experiment you're planning or just ran. Bring the story, not the data. We'll use a few as examples in the open forum.

You'll use

DOE basics (factors, levels, interactions, aliasing). If you've run a DOE before, you're ready.
